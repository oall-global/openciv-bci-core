# 图示连接向导 · 0.1.17

首次安装进入设备页。六步均有本地 SVG 图示：USB 准备 → 连接方式 → 网络配置 → 寻找设备 → 验证采集 → 连接完成。

## USB 配置

按用户提供的厂家聊天协议实现，采集过程仍使用 Wi-Fi。

1. 插好 USB、打开设备，点击「检查 USB 连接」。扫描系统串口，115200 波特率发送 `connect`；最多 16 个候选，8 路并行。仅身份回复匹配的串口可配置，多个匹配时由用户选择。
2. 支持 `eeg` 以及实机回复 `eeg-2-16` / `eeg-2-16-网络名-IP`。保留接收窗口等待延迟到达的网络信息。默认无换行，另可选 LF / CRLF。
3. 直连配置发 `1|热点名称|密码`；路由器配置发 `2|网络名称|密码`。发送前再次验证设备身份。蓝牙配置不在本次两种网络模式范围内。
4. 名称 1–32 UTF-8 字节、密码 8–63 字节；拒绝协议分隔符、换行、空字符。当前界面支持带密码的网络。密码不写入偏好、日志、诊断；发送后或离开向导即清除输入。
5. 原协议未定义配置成功回包。完整写入仅显示「配置已发送，等待无线验证」，不认定设备已经应用设置。
6. 直连时用户在 Windows Wi-Fi 中选择刚设置的热点；路由器模式保持电脑和设备在同一可通信局域网。可再次通过 USB 读取设备地址，或搜索 / 手动验证地址。

## 连接验证与恢复

- 设备发现与 `/board` HTTP 探测均不能直接完成向导。大小写兼容实际 `Cyton` 回复。
- 当前硬件按用户确认固定 Cyton + Daisy 16 通道；固件 `/board` 报告 32 通道会显示，不覆盖采集配置。
- 本次连接、相同 epoch、16 通道有限数据、每帧更新时间小于 1.5 秒，持续至少 3 秒后才能完成。演示、旧 epoch、过期数据不能通过。
- 完成后才保存模式 / 地址 / 采样率 / 本地端口；可以进入佩戴检测或工作台。断流撤销有效状态。
- 停止连接、修改配置、失败重试、重新读取地址、重新连接上次设备均有入口。已有采集时先断开；佩戴测试进行中先取消检测。
- 直连模式可「断开并返回原 Wi-Fi」：先停止采集，再打开 Windows 设置，由用户选择原网络。不会静默切换电脑网络。
- 无 USB 身份回复时保留热点配网。通过验证过的设备地址打开本机配网页面，密码由设备页面接收；附官方配网说明入口。
