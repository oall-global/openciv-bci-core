# 原则

这里记录本项目已经确定的方向。提交界面、文案或数据格式方面的改动前请先读；想改变其中某一条，请先开 issue 讨论。

## 1. 定位

本项目是开源文明 BCI-001 的核心部分：连接设备、采集、保存和处理 16 通道脑电，并通过本机接口交给其他程序。它是给想自己摆弄和二次开发的人用的底座。

- **只做基础的部分。** 佩戴指引、能力（识别状态并控制设备）、灯、游戏、实验和报告等建立在脑电之上的内容不在这里。
- **简化操作，不简化真实。** 信号处理是真的；结果如实显示，失败、跳过、不明显都照实说，不做假的"成功"。
- **在现有界面上微调。** 已有页面优先改进细节，不推倒重做。

## 2. 数据与开源

- 所有脑电数据只在本机（或手机上）处理和保存，不上传、不同步、不做遥测。
- 只有用户主动录制时才保存数据，并能在应用里找到和删除。
- 公开的代码就是发布的版本，不存在另一套闭源实现。

## 3. 文案

- **正式、平实、好懂。** 不用孩子气的说法和表情符号。
- **陈述事实，不讨好用户。**
- **不写没有用的解释。** 界面上不放常驻的说明段落、副标题或提示条。概念解释放进「?」弹窗和概念手册，用户需要时再看。一步操作需要的提示，限一句话。
- **不做医疗、保健表述。** 不写诊断、治疗、康复、健康评估、改善睡眠 / 焦虑 / 专注。「医疗」「诊断」只出现在否定句中（如「不能用于医疗诊断」）。
- **不暗示能读出想法。**
- **概念手册里不出现其他品牌或厂商名称。**

## 4. 界面叫法

界面名称保持一致，不随意改名：

| 叫法 | 指的是 |
|---|---|
| 信号工作台 | 首页，连接后看信号的地方 |
| 主图 · 单图 · 左右 · 上下 · 四宫格 | 工作台的五种布局 |
| 佩戴检查 | 电极接触图（标题栏「佩戴 n/16」打开） |
| 相对基线 | 频段能量与放松时参考的比值，记作 1.2× |
| 脑电数据库 | 本机所有脑电记录，每段一张卡片，点开是数据详情 |
| 添加脑机接口 | 小程序里配对设备的流程 |
| 概念手册 | 概念解释，「?」都链接到这里 |
| 开发者工作台 · 应用接口 | 本机 WebSocket 开发接口 |

## 5. 流程

- **默认路径越短越好。** 不轻易增加确认页、说明页或额外步骤。
- **对外输出默认关闭。** 开发接口需要用户自己打开，只监听本机。
- **结果如实。** 失败和跳过要如实显示，不显示成功或已完成。

## 6. 硬件事实

文案必须与实际硬件一致：

- 开关在设备侧面、USB 接口上方，推到上方、指示灯亮绿色为开机。
- USB 只在配对（设置 Wi-Fi）时使用；正常使用时拔掉 USB，通过 Wi-Fi 采集。
- 参考电极在头顶，接地电极（GND，接 BIAS）在额头中间偏上；没有耳夹。

## 7. 信号处理

- 波形显示、µVrms 和饱和判断与 OpenBCI GUI 一致：5–50 Hz 带通、去除 50/60 Hz 工频；最近 3 秒原始值超过量程 75% 为接近饱和，超过 90% 为饱和。由 `tests/display-filter.cjs` 和 `engine/rail.py` 保证。
- 电极接触颜色按饱和判断：良好 / 一般 / 需调整 / 未接触，圆点大小不表示幅度。
- 连接后自动测量 Fp1 阻抗判断是否戴上；其余阻抗测量由用户发起。

## 8. 已经否决的方向

| 方向 | 原因 |
|---|---|
| 推倒重做整套界面 | 在现有界面上改进细节 |
| 工作台布局改名（如「信号概览」） | 「主图」等叫法已固定 |
| 常驻说明条、新手提示条、每个控件旁的解释 | 解释放进「?」和概念手册 |
| 接触图用圆点大小表示信号幅度 | 用户难以理解 |
| 在应用里提供「模拟设备」 | 只用于开发和测试（`npm start -- --demo`） |
