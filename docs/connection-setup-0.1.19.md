# 普通用户连接流程 · 0.1.19

1. 打开设备电源，插 USB 数据线，点击「识别设备」。识别到唯一设备后自动进入连接方式，无需勾选准备事项；多台设备才要求选择。
2. 「使用现有 Wi-Fi」让电脑继续上网；「直连电脑」使用设备热点。默认采用设备报告的现有模式，不改写设备配置。更换网络/模式时才显示名称和密码，点击「保存并连接」发送设置。密码不保存。
3. 路由器模式自动读取 USB 地址、尝试访问、搜索并连接。直连模式提示在 Windows 中连接设备热点，返回后点击「已连接热点，继续」。无需填写 IP、逐项检查或手动保存。

设备已配网时，可从首页跳过 USB。已知地址及采样率、端口、串口命令结尾放入默认折叠的高级设置；热点配网页面保留为故障处理入口。修改网络不会由页面加载或模式选择自动触发。

真实连接的同一 epoch、16 通道有限数据连续至少 3 秒才自动完成并保存。演示数据、过期数据或旧连接数据不予通过。连接成功不代表电极接触良好，下一步提供佩戴检查。USB 配置发送成功不当作设备联网确认；找不到设备保留重试入口。

验证：生产构建；Electron 测试夹具覆盖现有配置免输密码、AP 配置、失败重试、密码不持久化、连续数据自动完成、旧帧/演示/断流拒绝，以及小窗口布局。配置和 EEG 使用测试夹具，不代表本次已对真实设备执行网络改写或无线采集验收。
