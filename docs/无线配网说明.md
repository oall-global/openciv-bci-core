# 无线连接开源文明 BCI-001

不需要 USB 线。用手机或电脑，几分钟把设备接入你家的 Wi-Fi。

## 准备

- 设备已充电。
- 设备的序列号（SN），印在设备标签上，例如 `OCBCI01010100002`。
- 你家 Wi-Fi 的名称和密码。设备只能连接 **2.4 GHz** 的 Wi-Fi；如果路由器把 2.4 GHz 和 5 GHz 分成两个名称，请选 2.4 GHz 的那个。

## 步骤

1. **打开设备。** 把电源开关向上推到顶，指示灯亮起。
2. **连接设备热点。** 在手机或电脑的 Wi-Fi 列表里，选择和序列号同名的热点（例如 `OCBCI01010100002`），输入热点密码（见设备标签或快速上手卡）。
   - 手机提示「此网络无法上网」时，选择「保持连接」。
3. **打开配网页面。** 在浏览器地址栏输入 `192.168.4.1/wifi`，打开「无线配网」页面。
4. **选择你家的 Wi-Fi。** 在「附近的 WiFi」里选择你家的网络；列表里没有时，点「重新扫描」，或在「SSID」里直接输入名称。
5. **输入密码，保存。** 填入 Wi-Fi 密码，点「保存并重启」。设备会重启并加入你家的 Wi-Fi，约需 10–20 秒。
6. **回到你家的 Wi-Fi。** 手机或电脑会自动断开设备热点；如果没有，请手动切回你家的 Wi-Fi。
7. **在 App 里连接。** 电脑连着同一个 Wi-Fi，打开开源文明 BCI-001 App，点击连接，App 会在网络里找到设备。

## 遇到问题

| 情况 | 处理 |
|---|---|
| 找不到设备热点 | 确认设备已开机；长按设备按键 3 秒，设备会以默认热点重新启动。 |
| 打不开 `192.168.4.1/wifi` | 确认仍连着设备热点；关闭手机的「移动数据」后再试。 |
| 列表里没有你家的 Wi-Fi | 你家的 Wi-Fi 可能只有 5 GHz；请在路由器里打开 2.4 GHz，或让设备靠近路由器后点「重新扫描」。 |
| 保存后 App 找不到设备 | 多半是密码输错，或电脑与设备不在同一个 Wi-Fi。长按设备按键 3 秒回到热点，从第 2 步重新配置。 |
| 换了路由器或 Wi-Fi 密码 | 长按设备按键 3 秒回到热点，从第 2 步重新配置。 |

设备只把脑电发给你同一网络里的电脑，不连接任何云端服务。
