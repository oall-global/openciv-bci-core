# 工作台扩展 · 0.1.28

在「信号工作台」每个面板左上角的图表菜单选择内容，支持单图、左右、上下、四宫格和单面板放大。

| 选项 | 使用与范围 |
|---|---|
| 时间序列 | 16通道、8秒实时波形；保留0.1.27的CSS像素绘制 |
| 功率频谱 / 多通道频谱 | 1–40 Hz、4秒Welch；多通道可切换线性/对数，通道面板勾选参与叠加 |
| 频段功率 / 时频图 | 原有频段积分与30秒时频历史 |
| 二维头皮图 | RMS或Alpha占比；标准16电极示意位置，点击联动；反距离插值，不等同原版求解器 |
| 脑电同步 / 通道状态 | 原有3D电极与Railed；未修改Railed计算 |
| 丢包与传输 | 本会话累计接收/估计缺失/重复/不确定跳变、批次间隔趋势、可见波形绘制FPS |
| 加速度 | BrainFlow三轴解码数据的批次均值；需确认固件处于加速度模式。零值不证明硬件静止 |
| 肌电幅度 | 最近1秒20–min(90,0.4fs) Hz RMS，排除50/60 Hz ±2 Hz；饱和通道无效 |
| 肌电虚拟摇杆 | 四方向可选通道，差值按满量程归一化到−1..1；只在屏幕显示，不控制实体设备 |
| Focus模型观察 | BrainFlow内置默认分类器、4秒有效通道数据，每秒估计一次Mindfulness/Restfulness；未经个人验证，不是专注度测量或准确率 |
| 事件标记 | 可自定义或快捷写入睁闭眼/动作事件，不用开启网络接口 |
| 录制与回放 | JSONL流式写入原始脑电、频谱、特征、标记；载入后工作台图表联动，支持暂停、拖动、0.5–4倍速 |
| 数据输出 | 本机认证WebSocket开关、密钥、客户端状态、协议示例 |
| 更多功能 / 支持条件 | 脉搏、模拟/数字输入、Ganglion、其他网络协议的实际支持边界 |

## 实验与录制

1. 连接设备，选择「录制与回放」，点击「开始录制」并选择一个新文件名。
2. 另一个面板选择「事件标记」，在动作开始/结束时添加标记。
3. 点击「停止录制」，再「打开录制文件」。播放/暂停或拖动进度，其余图表随之更新。
4. 点击「返回实时采集」退出回放。切换离开工作台也会退出当前回放；原始录制仍由主进程持续保存，建议先停止再离开。

不自动录制、不覆盖已有文件。文件上限128 MB，磁盘异常或写入积压会结束录制。断流、检测、重连会结束当前文件，重新采集需另开新文件。标记记录主机收到时间及最近样本序号，不是精确刺激同步。未录制时仅保留最近30条标记。回放数据不进入开发接口/能力校准/实体设备控制，真实采集若仍连接可在后台继续。

## 和 OpenBCI GUI 的差异

不是18组件的完整原样移植。新二维图使用反距离插值，EMG使用明确频段RMS而非原版自适应阈值，Focus使用当前随包BrainFlow默认模型与固定4秒窗口，频谱仍为1–40 Hz。丢包值是序号估计：Wi-Fi步长1、Daisy串口步长2，重复及不确定跳变单列；无法识别整圈256计数丢失，也不是网卡层丢包率。

未添加未经协议确认的模拟/数字输入、脉搏传感器图及Ganglion适配。数据输出仍为本机WebSocket，未覆盖LSL/OSC/UDP。加速度当前仅具备解析与展示，不宣称已验证这台定制固件的辅助模式。
